INDIA JOB SCANNER
=================

IMPORTANT — READ THIS FIRST
---------------------------
Netlify's drag-and-drop box (app.netlify.com/drop) will NOT work for
this app. It publishes web pages only; it does not deploy the small
backend program that reads the career portals. If you drag-and-drop it,
the site loads but every scan fails.

Use ONE of the two methods below instead. Both are easy.


=====================================================================
METHOD 1 — PUT IT ONLINE  (recommended, about 5 minutes)
=====================================================================

You need Node.js first:  https://nodejs.org  (click the big LTS button,
install it, accept all the defaults)

Then:

1. Unzip this folder somewhere easy, like your Desktop.

2. WINDOWS:  double-click  deploy.cmd
   MAC:      open Terminal in this folder and type:  bash deploy.sh

3. A browser window opens asking you to sign in to Netlify.
   Create a free account if you do not have one, then click "Authorize".

4. Back in the black window you will be asked a few questions.
   Answer them like this:

      What would you like to do?   ->  Create & configure a new project
                                       (use arrow keys, press Enter)
      Team                         ->  press Enter
      Project name                 ->  type a name, or press Enter

5. Wait about a minute. It prints:

      Website URL:  https://your-name.netlify.app

   That address is your live bot. Open it. Done.

TO UPDATE IT LATER
   Change whatever you want, then run deploy.cmd again.


=====================================================================
METHOD 2 — RUN IT ON YOUR OWN COMPUTER  (2 minutes, nothing online)
=====================================================================

1. Install Node.js:  https://nodejs.org

2. Open Command Prompt inside this folder.
   Windows tip: click the folder's address bar, type  cmd  press Enter.

3. Type:     npm start

4. Open:     http://localhost:8888

   Stop it with Ctrl + C. Nobody else can see it — it runs only
   on your machine, and only while that window is open.


=====================================================================
DID IT WORK?
=====================================================================
Open the site, run one scan, then click the "Connector status" tab.

  Portals listed with job counts    ->  working correctly
  A message about a missing backend ->  you used drag-and-drop.
                                        Use Method 1 above instead.


=====================================================================
IF YOUR NETLIFY SITE SAYS THE BACKEND IS MISSING
=====================================================================
This means the site was created by dragging files onto Netlify.
Fix it without losing your web address:

  1. Open Command Prompt in this folder
  2. Type:   npm run deploy
  3. When asked "What would you like to do?", choose
     "Link this directory to an existing project" and pick your site.

Your existing address keeps working, and the backend appears.


=====================================================================
GET MANY MORE RESULTS  (free, optional, 3 minutes)
=====================================================================
Out of the box the bot reads company career portals directly. Adding a
free Adzuna key widens it to nearly every employer advertising in India.

1. Sign up at  developer.adzuna.com  and copy your App ID and App Key.

2. ON NETLIFY:
     Site configuration > Environment variables > Add a variable
        ADZUNA_APP_ID   = your id
        ADZUNA_APP_KEY  = your key
     Then run  deploy.cmd  again.

   ON YOUR COMPUTER:
     Make a file called  .env  in this folder containing:

        ADZUNA_APP_ID=your_id
        ADZUNA_APP_KEY=your_key

The bot works without this. You just get fewer listings.
